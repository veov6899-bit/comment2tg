# comment2tg — сайтын сэтгэгдлийг Telegram суваг руу автоматаар дамжуулагч

Дурын сайтын сэтгэгдлийн хэсгийг тодорхой хугацаа тутам шалгаад, **шинэ сэтгэгдэл** гарч ирмэгц Telegram сувагт автоматаар постлоно. Нэг сэтгэгдлийг хоёр удаа илгээхгүй (`state/` фолдерт тэмдэглэж явдаг).

> **Одоогийн байдал:** 6 сайт тохируулагдсан — zarig.mn, ikon.mn, isee.mn, news.mn, unuudur.mn, shuurhai.mn.
> Бот болон суваг холбогдсон (утгууд нь `secrets.json` дотор). 424 хуучин сэтгэгдэл "уншсан" болсон тул
> зөвхөн **одооноос хойшхи шинэ** сэтгэгдлүүд сувагт орно.
>
> **Токен хаана байдаг вэ:** `secrets.json` файлд (энэ нь `.gitignore`-д бичигдсэн тул GitHub руу хэзээ ч орохгүй). Үүлэн орчинд `TG_BOT_TOKEN` / `TG_CHAT_ID` орчны хувьсагчаас уншина.

---

## 1. Суулгах (нэг удаа)

```bash
pip install -r requirements.txt
```

## 2. Telegram бот бэлдэх

1. Telegram дээр **@BotFather** руу орж `/newbot` → нэр өгч **токен** авна.
2. Өөрийн сувагтаа тэр ботыг **администратор** болгож нэмнэ (Post messages эрхтэй).
3. `secrets.json` файлд бөглөнө:

```json
{ "bot_token": "1234567890:AAH...", "chat_id": "-100..." }
```

> Хаалттай суваг бол `@нэр` байхгүй. Тэр тохиолдолд сувагт нэг мессеж бичээд
> `https://api.telegram.org/bot<ТОКЕН>/getUpdates` руу орж `chat.id` (-100...) утгыг хуулна.

Шалгах:

```bash
python forwarder.py --test-telegram
```

## 3. ⭐ Шинэ сайт нэмэх — зөвхөн ЛИНК өгнө

Зөвхөн **сайтын хаягийг** өгөхөд л болно:

```bash
python forwarder.py --add https://сайт.mn/
```

Тодорхой мэдээний линк өгвөл бүр хурдан:

```bash
python forwarder.py --add https://сайт.mn/мэдээ/12345
```

Скрипт өөрөө:

0. Өгсөн хуудсанд сэтгэгдэл байхгүй бол **нүүрнээс нь мэдээнүүдийг олж, сэтгэгдэлтэйг нь хайж** олно (20 хүртэл мэдээ шалгана),

1. WordPress сайт мөн эсэхийг шалгана (мөн бол REST API-аар шууд уншина),
2. HTML доторх сэтгэгдлийн блокуудыг **автоматаар таньж** selector-ийг гаргана,
3. Сэтгэгдэл нь JavaScript массиваар ирдэг бол (жишээ нь **ikon.mn**) түүнийг уншина,
4. Сэтгэгдлээ **тусдаа хаягаас (AJAX)** ачаалдаг бол тэр хаягийг өөрөө олж дагана,
5. Мэдээний линкийн загварыг (regex) таамаглаж, бэлэн блокыг `sites.json`-д бичнэ.

Дараа нь шалгана:

```bash
python forwarder.py --site сайт.mn --once --dry-run
```

`--dry-run` нь Telegram руу илгээхгүй, зөвхөн дэлгэц дээр харуулна (юу ч "уншсан" болгохгүй).

**Хэрэв "сэтгэгдэл олдсонгүй" гэвэл:** тэр мэдээнд сэтгэгдэл байхгүй байсан байх. Сэтгэгдэлтэй өөр мэдээгээр дахин `--add` хийнэ үү.

### Туршиж шалгасан монгол сайтууд

| Сайт | Ажиллах уу | Хэрхэн уншдаг |
|---|---|---|
| **zarig.mn** | ✅ | Мэдээний HTML дотроос шууд |
| **news.mn** | ✅ | WordPress REST API |
| **unuudur.mn** | ✅ | Мэдээний HTML дотроос шууд |
| **ikon.mn** | ✅ | `/c/{id}` хаягаас JS массив |
| **isee.mn** | ✅ | `/comments?id={id}` хаягаас JSON |
| **shuurhai.mn** | ✅ | `/comments/{id}` хаягаас HTML |
| gogo.mn | ❌ | Сэтгэгдлээ зөвхөн POST хүсэлтээр өгдөг |
| caak.mn | ❌ | GraphQL (зөвхөн POST) |
| olloo.mn | ❌ | Cloudflare хамгаалалт нэвтрүүлэхгүй |

Дээрх ✅ сайтуудыг нэмэх бол ердөө:

```bash
python forwarder.py --add https://ikon.mn/n/3pst
python forwarder.py --add https://isee.mn/n/94236
```

(сэтгэгдэлтэй ямар ч мэдээний линк болно — дугаар нь хамаагүй)

Гараар судлах бол:

```bash
python forwarder.py --inspect https://сайт.mn/мэдээ/12345
```

## 4. Эхлүүлэх

```bash
python forwarder.py --seed
```

Одоо байгаа бүх сэтгэгдлийг "уншсан" гэж тэмдэглэнэ — ингэснээр эхний ажиллагаанд хуучин олон зуун сэтгэгдэл сувгийг дүүргэхгүй. **Заавал эхэлж ажиллуулаарай.**

Дараа нь тасралтгүй:

```bash
python forwarder.py --loop
```

(эсвэл `run-loop.bat` дээр давхар дарна). Одооноос хойш нэмэгдсэн шинэ сэтгэгдлүүд л сувагт орно.

## 5. sites.json дотор юу байдаг вэ

Ганц сайтын блок ойролцоогоор ийм харагдана:

```json
{
  "name": "zarig.mn",
  "enabled": true,
  "mode": "auto",
  "discover": {
    "from": ["https://zarig.mn/", "https://zarig.mn/politics"],
    "link_selector": "a[href]",
    "link_pattern": "^https://zarig\\.mn/[a-z0-9]{2,6}$",
    "max_pages": 30
  },
  "pages": [],
  "comment": { "item": ".comments__list", "text": ".comments__list-body--text" },
  "filter": { "min_length": 2, "include_keywords": [], "exclude_keywords": [] }
}
```

**Нэг сайтад олон линк байгаа нь хэвийн зүйл.** Тэдгээр нь өөр өөр үүрэгтэй:

| Талбар | Тайлбар |
|---|---|
| `discover.from` | Шинэ мэдээг ХААНААС хайхыг заана (нүүр хуудас, ангиллын хуудсууд). Олон байх тусам илүү олон мэдээ хамрагдана |
| `discover.link_selector` | Тэр хуудсан дээрх линкийн CSS selector (`a[href]` = бүх линк) |
| `discover.link_pattern` | Олдсон линкүүдээс зөвхөн МЭДЭЭГ шүүх regex (ангилал, сурталчилгааг хасна) |
| `discover.max_pages` | Нэг удаад хамгийн ихдээ хэдэн мэдээ шалгах |
| `pages` | Байнга шалгах тогтмол хаягууд (заавал биш) |
| `mode` | `auto` = бүтцийг өөрөө таних, `html` = зөвхөн selector-оор, `wordpress` = REST API-аар |
| `comment.*` | Гараар засах бол selector-ууд. `auto` үед хоосон байж болно |
| `filter.include_keywords` | Зөвхөн эдгээр үг агуулсан сэтгэгдлийг илгээнэ (хоосон = бүгд) |
| `filter.exclude_keywords` | Эдгээр үг агуулсныг алгасна |

Ерөнхий тохиргоо (`settings`):

| Талбар | Тайлбар |
|---|---|
| `interval_seconds` | Хэдэн секунд тутам шалгах (300 = 5 минут) |
| `max_send_per_run` | Нэг ажиллагаанд хамгийн ихдээ хэдэн мессеж илгээх |
| `include_author` | Сэтгэгдэл бичсэн хүний нэр/IP-г мессежид оруулах эсэх (үндсэн: **false**) |
| `show_link` | Мэдээний гарчиг/линкийг мессежид оруулах эсэх (үндсэн: **false** — зөвхөн сэтгэгдлийн текст) |
| `show_site` | Сайтын нэрийг мессежийн эхэнд харуулах эсэх (үндсэн: **true**) |
| `show_date` | Сэтгэгдлийн огноог харуулах эсэх (үндсэн: **false**) |
| `tg_attempts` | Telegram руу хэдэн удаа дахин оролдох (сүлжээ муу үед хэрэгтэй) |
| `proxy` | VPN/прокси ашиглах бол жишээ нь `"socks5://127.0.0.1:1080"` |

> **Хувийн мэдээлэл:** зарим сайт (жишээ нь zarig.mn) сэтгэгдэл бичигчийн **IP хаягийг** нэрийн оронд харуулдаг. Тиймээс `include_author` анхнаасаа `false` байгаа. Хэрэгтэй бол л асаана уу.

### Гараар нэмэх жишээ (WordPress сайт)

```json
{
  "name": "жишээ.mn",
  "enabled": true,
  "mode": "wordpress",
  "base_url": "https://жишээ.mn",
  "per_page": 20,
  "filter": { "min_length": 2, "include_keywords": [], "exclude_keywords": [] }
}
```

## 6. Telegram сүлжээний асуудал (энэ компьютер дээр)

Энэ компьютерын интернэтээс `api.telegram.org` руу залгах нь **тогтворгүй** — 5 оролдлогоос ойролцоогоор 1 нь л амжилттай (ISP-ийн хязгаарлалт байх магадлалтай). Тиймээс скрипт:

- эхлээд ердийн нэрээр, дараа нь Telegram-ийн шууд IP-үүдээр (SNI-г зөв хадгалж) ээлжлэн оролдоно,
- амжилттай болсон хаягийг цээжилж дараагийн удаа шууд ашиглана,
- `settings.tg_attempts` (үндсэн 15) удаа хүртэл дахин оролдоно.

Мессеж эцэст нь хүрдэг, гэхдээ заримдаа 1–3 минут зарцуулна. **VPN асаавал шууд хурдан болно.** Хамгийн тогтвортой нь VPS сервер дээр ажиллуулах.

## 7. ⭐ Үнэгүй 24/7 ажиллуулах (GitHub Actions)

Компьютероо унтраасан ч ажиллана, мөн **Telegram-ийн сүлжээний асуудал ч арилна** (GitHub-ын серверээс Telegram руу шууд холбогдоно).

**1.** [github.com/new](https://github.com/new) дээр шинэ репо үүсгэнэ — нэр нь `comment2tg`, төрөл нь **Public**.

> Public байх нь чухал: нийтийн репод Actions-ийн минут **хязгааргүй үнэгүй**. Private бол сард 2000 минут л үнэгүй тул `.github/workflows/comment2tg.yml` доторх cron-оо `"0 * * * *"` (цаг тутам) болгоно уу.
>
> Токен репод **ОРОХГҮЙ** — `secrets.json` нь `.gitignore`-д бичигдсэн.

**2.** Энэ фолдероос дараах командуудыг ажиллуулна (`ХЭРЭГЛЭГЧ` хэсэгт өөрийн GitHub нэрээ бичнэ):

```bash
git remote add origin https://github.com/ХЭРЭГЛЭГЧ/comment2tg.git
git branch -M main
git push -u origin main
```

**3.** Репо дотроо **Settings → Secrets and variables → Actions → New repository secret** гэж орж 2 нууц утга нэмнэ:

| Нэр | Утга |
|---|---|
| `TG_BOT_TOKEN` | @BotFather-аас авсан токен (`secrets.json` дотор байгаа) |
| `TG_CHAT_ID` | сувгийн ID (`secrets.json` доторх `chat_id`) |

**4.** **Actions** таб → зүүн талаас `comment2tg` → **Run workflow** дарж эхний удаа гараар шалгана.

**5.** Түүнээс хойш цаг тутам нэг ажиллагаа эхэлж, тэр нь **55 минутын турш 5 минут тутам** шалгана.

> Яагаад ингэсэн бэ: GitHub-ын "5 минут тутам" гэсэн хуваарь бодит байдалд найдваргүй — заримдаа огт асдаггүй. Нэг ажиллагааг удаан үргэлжлүүлснээр GitHub цагт ганц удаа асаахад л хангалттай болсон. Уншсан сэтгэгдлийн тэмдэглэгээ (`state/`) репо руугаа буцаж хадгалагдах тул давхар илгээхгүй.

**6.** Компьютер дээрээ `run-loop.bat`-ыг ажиллуулж байсан бол **зогсооно уу** — эс бөгөөс нэг сэтгэгдэл хоёр удаа орно.

> GitHub-ын cron заримдаа 5–20 минут хоцордог (энэ нь GitHub-ын онцлог). Яг секунд алдалгүй хэрэгтэй бол компьютер дээрээ `--loop` ажиллуулах нь хурдан.

## 8. Компьютер асахад автоматаар ажиллуулах (deploy хийхгүй бол)

**Task Scheduler** (Даалгавар товлогч):

1. `Create Task` → нэр: `comment2tg`
2. Triggers → New → `At startup`
3. Actions → New →
   - Program: `pythonw.exe`-ийн бүтэн зам (жишээ нь `C:\Users\pc\AppData\Local\Programs\Python\Python311\pythonw.exe`)
   - Arguments: `forwarder.py --loop`
   - Start in: `C:\Users\pc\Downloads\comment2tg`
4. Conditions → `Start only if on AC power`-ийг **унтраана**.

`pythonw.exe` ашиглавал хар цонх харагдахгүй арын дэвсгэрт ажиллана.

## 9. Түгээмэл асуудал

| Асуудал | Шалтгаан / шийдэл |
|---|---|
| `--add` "сэтгэгдэл олдсонгүй" гэж байна | Тэр мэдээнд сэтгэгдэл байхгүй. Сэтгэгдэлтэй өөр мэдээгээр дахин оролдоно уу |
| Facebook/Disqus сэтгэгдэл | Тэдгээр нь гуравдагч талын систем — уншиж чадахгүй |
| Telegram `chat not found` | Бот сувагт admin болоогүй, эсвэл `chat_id` буруу |
| Нэг сэтгэгдэл дахин дахин ирж байна | Сайт ID өгдөггүй бөгөөд текст нь өөрчлөгддөг. `comment.id_selector`-оор жинхэнэ ID-г нь заана |
| Хуучин сэтгэгдлүүд бөөнөөрөө орлоо | `--seed` хийхээ мартсан. `state/` доторх файлыг устгаад дахин `--seed` |
| Сувагт хэт олон мессеж | `settings.max_send_per_run`-ыг багасгах, эсвэл `filter.include_keywords` тавих |

## ⭐ Хамгийн хялбар арга — manage.bat

`manage.bat` дээр давхар дарахад цэс гарч ирнэ:

```
  1) Сайтуудыг харах
  2) ЗӨВХӨН нэг сайт үлдээх
  3) Шинэ сайт нэмэх
  4) Сайт асаах / унтраах
  5) Туршиж үзэх (илгээхгүй)
  6) GitHub руу илгээх
  7) Энэ компьютер дээр ажиллаж байгаа эсэхийг шалгах
  0) Гарах
```

Дугаараа бичээд Enter дарна. Сайт солих бүрд "GitHub руу одоо илгээх үү?" гэж асууна —
Enter дарвал `git pull --rebase` → `commit` → `push` гурвыг өөрөө хийнэ.

Шинэ сайт нэмэхэд (сонголт 3) хуучин сэтгэгдлүүдийг нь автоматаар "уншсан" болгож,
сувагт бөөнөөр цутгахаас сэргийлнэ.

## Сайт асаах / унтраах (командаар)

```bash
python forwarder.py --list
```

Тохируулсан бүх сайтыг ON/off төлөвтэй нь харуулна. Дараа нь:

```bash
python forwarder.py --only ikon.mn
```

Зөвхөн нэрлэсэн сайтыг үлдээж бусдыг унтраана. Ганцхан сайтыг унтраах/асаах бол `--disable <нэр>` / `--enable <нэр>`.

> Унтраасан сайтын тохиргоо болон "уншсан" тэмдэглэгээ хэвээр үлддэг — буцааж асаахад хуучин сэтгэгдлүүд дахин орохгүй.

## Командын жагсаалт

```bash
python forwarder.py --add URL             # ⭐ шинэ сайт нэмэх (линк өгөхөд л болно)
python forwarder.py --list                # сайтуудыг жагсаах (ON/off)
python forwarder.py --only ikon.mn        # зөвхөн нэг сайтыг үлдээх
python forwarder.py --inspect URL         # бүтцийг нь гараар судлах
python forwarder.py --test-telegram       # бот шалгах
python forwarder.py --seed                # одоогийн бүгдийг уншсан болгох
python forwarder.py --once --dry-run      # илгээхгүй туршилт
python forwarder.py --once --limit 1      # зөвхөн 1 ширхэг илгээх
python forwarder.py --site zarig.mn --once
python forwarder.py --loop                # тасралтгүй
```
